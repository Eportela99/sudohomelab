# Books & Audiobooks

Your personal Audible and Kindle, minus the subscription.

Servers for audiobooks, podcasts, ebooks and comics with great mobile apps.

| App | What it does | Platforms | Status |
| --- | --- | --- | --- |
| **Audiobookshelf** | Audiobook & podcast server with progress sync. | Proxmox, Linux, TrueNAS, Windows, macOS | Planned |
| **Komga** | Comics & manga server with a slick web reader. | Proxmox, Linux, TrueNAS, Windows, macOS | Planned |
| **Kavita** | Fast reader for ebooks, manga and comics. | Proxmox, Linux, TrueNAS, Windows, macOS | Planned |
| **Calibre-Web** | Browse, read and send your Calibre library to e-readers. | Proxmox, Linux, TrueNAS, Windows, macOS | Planned |

## Layout

Scripts go in one folder per platform:

Books_Audiobooks/
